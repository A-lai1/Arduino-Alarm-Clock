# Arduino Alarm Clock

This is an Alarm Clock made with an Arduino Uno R3.
It utilizes an LCD module, a DS3231 RTC module, an IR remote and receiver, a passive buzzer, and an LED.
Users can set and delete alarms. They can also check the time, the date, and the day of the week.
Alarms are stored in EEPROM, so they are saved even if power is disconnected.
